## 2. Re-cleaning `/tmp/elevate-rag/*.html` → `/tmp/elevate-rag-clean/`

Built a pure-Python-stdlib cleaner (`/tmp/elevate-rag/work/clean.py`) using `html.parser.HTMLParser`:

1. Walk the DOM; only emit content that lives **inside `<main>...</main>`**.
2. Drop tags wholesale (with all their content): `<script>`, `<style>`, `<noscript>`, `<iframe>`, `<svg>`, `<header>`, `<nav>`, `<footer>`, `<aside>`, `<form>`, `<button>`. These were the nav/header/footer/ticker removal targets.
3. Outside `<main>`, emit nothing — this kills the entire `<head>` (incl. JSON-LD schema, og:tags) and the body content outside `<main>` (e.g. cart-drawer aside, wholesale-cta trailer sections that were outside `<main>` in some pages).
4. Re-wrap output as a minimal `<!DOCTYPE html><html><head><title>+<description>+<canonical></head><body><main>…</main></body></html>` so AnythingLLM still gets a parseable doc with title metadata.
5. Collapse runs of whitespace.

No `ticker`/`marquee`/`news-ticker`/`announcement-bar`/`top-bar`/`cookie-banner` strings appear in the source corpus (verified with grep across all 23 files) — the site didn't ship those, so the boilerplate in question is the global header/footer/nav only.

## 5. Chat timing (baseline 10–14 s)

Endpoint: `POST /api/v1/workspace/elevate/chat` with header `Origin: http://localhost:3001`, payload `{"message": "...", "mode": "chat"}`. AnythingLLM returns a single SSE event of shape `{"type":"textResponse","close":true,"chatId":N,"textResponse":"<think>…</think><answer>"}` (no per-token streaming — the whole answer is delivered in one frame).

Wall time = full request to last byte received.

### Q1 — "Do you ship internationally?"

Steady-state (after warm-up):

| run | wall (s) | answer chars | sources |
|---:|---:|---:|---:|
| 1 | 8.01 | 97 | 0 |
| 2 | 5.31 | 97 | 0 |
| 3 | 5.44 | 97 | 0 |
| **avg** | **6.25** | | |
| **min** | 5.31 | | |
| **max** | 8.01 | | |

Model think excerpt:

> The context includes some info about being a distribution partner for academic institutions worldwide, but no explicit statement about international shipping. … the question is not directly covered by the provided context … We should not guess.

Answer:

> I don't have specific information about international shipping policies in the retrieved context.

✅ **Correctness:** The cleaned corpus does not contain an explicit shipping policy (the original `contact.html` was reduced to a 899-word page mostly about CTA sections, and the source data never had a dedicated shipping policy block). The model correctly **refused** to guess and surfaced the "I don't have that information" fallback — exactly the system-prompt behaviour: *"If the answer is not in the retrieved context, say you do not have enough information and ask for the missing detail."* No hallucinated shipping policy.

A separate first-call (cold, right after the embedding swap) measured **18.93 s** — that's the one-shot first-time-instantiation cost (LanceDB/vector-store first-touch + embedding-model warm). Subsequent calls are 5–8 s. The single-stream-event body length is ~2 KB.

Model think excerpt:

> … The context also includes a page about research with a link to research page. However, there is no explicit product list. According to instructions, we should answer based on retrieved context.

Answer:

> Based on the available information, Elevate Scientific offers research peptides and related laboratory supplies, such as quality‑verified materials for scientific research.

Sources retrieved (topN=3, all from new `site:*` docs):

1. `custom-documents/siteabout.html` (chunk 1, score 0.5003) — about-page overview paragraph
2. `custom-documents/siteabout.html` (chunk 2, score 0.4935) — about-page hero
3. `custom-documents/siteresearch.html` (score 0.4713) — research-page hero

✅ **Correctness:** Accurate but generic. Specific product names (BPC-157, AOD-9604, etc.) live in the individual `product_*.html` docs and the long `siteshop.html` (4,591 words), but `topN=3` + `similarityThreshold=0.25` means the broad "what does the company sell" query pulled only the about/research hero text. The model correctly avoided inventing product names it had no retrieved evidence for. Cold first-call was **20.55 s**; steady-state 8.8–15.7 s.
