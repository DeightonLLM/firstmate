# Image selection report

Unsplash search API responded successfully (HTTP 200) for all 16 concrete queries tested. Results varied substantially by wording: `pharmaceutical warehouse logistics` returned 2 results, `quality control laboratory` 13, and several broad medicine/logistics terms returned hundreds or more. The previous overly literal phrase was not a useful search filter.

All 10 posts now have a hero image selection recorded in `IMAGE-MANIFEST.md`. Each entry has an API-returned photo ID, photographer, profile link, and download location; descriptions and captions frame the photos as illustrative stock, not Core Distro's actual products or operations. Several results are generic and reused where relevant. No selected image depicts Core Distro's vials, stoppers, seals, or fill-finish line.

This deliverable is an attribution/selection manifest, not downloaded image assets and not edits to the post markdown. Posts with hero selections: 01, 02, 03, 04, 05, 06, 07, 08, 09, 10. Posts without a hero selection: none.
