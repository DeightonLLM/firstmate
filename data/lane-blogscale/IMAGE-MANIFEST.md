# Image manifest

**No post heroes selected because the dated plan supports no posts yet.** The Unsplash API was not queried and no image IDs, photographer attributions, profile links, or download locations are represented as selected. This is not a claim that no suitable images exist; image selection was not appropriate until there are supported post subjects.

When a post is supported by a real month-specific event, select at least one suitable Unsplash hero for it. At selection time, read the credential only from `~/.config/unsplash/credentials`; never print, log, or write the key. Verify each chosen photo ID against the Unsplash API and record the API-returned photographer, profile URL, photo URL, image hotlink and `download_location`. Follow the project's imagery guidance and label stock photography as illustrative, never as Core Distro product, facility, staff or operations.

The retrospective caveat must travel with every future post: **These are retrospective entries written after the fact, not contemporaneous news.**
